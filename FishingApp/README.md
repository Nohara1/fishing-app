# FishingApp

Помощник рыбака: карта водоёмов, справочник рыб, погода с оценкой клёва и подбор рецепта прикормки.

Стек: Vue 3, Vite, Vue Router, Pinia, SCSS. Карта — Яндекс. Погода — OpenWeather и Open-Meteo. Фаза луны — отдельный API. Приложение выкладывается на GitHub Pages, базовый путь `/fishing-app/`.

## Как запустить

Нужен Node `^20.19.0` или `>=22.12.0`.

```sh
npm install
npm run dev
```

Сборка и проверка продакшен-версии:

```sh
npm run build
npm run preview
```

При старте приложение один раз запрашивает геолокацию и по этим координатам тянет текущую погоду, почасовой прогноз и луну.

## Что уже сделано

### Каркас

- Тёмная оболочка: боковое меню слева, шапка страницы и контент справа.
- Четыре рабочих маршрута: `/` карта, `/fishes` рыба, `/weather` погода, `/bait` прикормка.
- Общий набор UI-компонентов подключается глобально из `src/components/ui/index.js`: кнопки, инпут, селект, диапазон, карточки, списки, теги, SVG-спрайт.
- Иконки меню переведены на SVG-спрайт (`vite-plugin-svg-icons`). Сейчас в спрайте только `pike` и `logo`, поэтому у всех пунктов меню одна и та же иконка.
- В сайдбаре крутится блок «Совет» со статичными подсказками.
- Шрифт Liberation Mono подключён локально.
- Pinia подключена. В стор вынесена только погода: координаты, текущая погода, почасовой прогноз и луна (`src/stores/weather.js`). Остальные страницы держат данные у себя в компоненте.

### Карта (`PageMap`)

Яндекс.Карта открывается и рисуется. Рядом с ней:

- поиск по названию водоёма;
- карточка «Сейчас на рыбалке»: температура воздуха, ветер, давление и фаза луны берутся из стора;
- список «Водоёмы рядом». Без поиска показываются первые три. Клик подсвечивает выбранный пункт.

Список водоёмов зашит в страницу. Это одни и те же примеры (Селигер, Волга, Рыбинское), у всех одинаковые рыбы и оценка. Центр карты зафиксирован на `[27.57, 53.9]`, это не геолокация пользователя. Меток на карте нет, клик по водоёму карту не двигает. Температура воды всегда `15°C`.

### Рыба (`PageFishes`)

Справочник из карточек. Работают поиск по названию и фильтр по сезону. Если ничего не нашлось, показывается пустое состояние.

Карточки — заглушка: шесть записей, у нескольких одинаковое имя «Карп», у всех латинское имя `Esox lucius`, картинки повторяются. Кнопка «Подробнее» ничего не открывает. У фильтра «Зима» стоит весенняя иконка.

### Погода (`PageWeather`)

Три вкладки.

| Вкладка | Откуда данные | Что уже живое |
| --- | --- | --- |
| Сейчас | OpenWeather `weather` + луна | Город, температура, описание, ветер, влажность, давление, видимость, фаза луны |
| Сегодня | OpenWeather `forecast` | Почасовые слоты на текущие сутки: время, температура, иконка, ветер, вероятность дождя |
| Неделя | Open-Meteo | Семь дней: день, иконка по коду погоды, дневная и ночная температура, вероятность осадков, восход |

На вкладке «Сейчас» считается оценка условий для рыбалки от 0 до 100. Веса: температура 30%, давление 25%, ветер 20%, облачность 15%, влажность 5%, луна 5%. По сумме выставляется подпись от «Очень плохие» до «Отличные», и каждый фактор показывается отдельно в блоке «Анализ условий».

Тексты вокруг этой оценки пока статичные: лучшие часы клёва, «идеально для щуки и окуня», советы на сегодня, «лучшие дни недели». Температура воды на вкладке «Сейчас» — прочерк.

### Прикормка (`PageBait`)

Форма условий ловли: рыба, тип водоёма, прозрачность, течение, температура воды, сезон, время суток, метод. Кнопка «Создать рецепт» сравнивает форму с тремя зашитыми рецептами и показывает тот, у которого больше совпадений. Если совпадений ноль, рецепт не выбирается. Кнопка сброса очищает форму и результат. Пока рецепт не создан, справа пустое состояние.

Рецепты: универсальная сладкая, для леща, для карпа. У каждого состав, шаги приготовления, консистенция, связка и аромат.

Глубина ловли в форме закомментирована. Кнопка «Сохранить пресет» ничего не сохраняет. Рецепты лежат прямо в `PageBait.vue`, отдельного стора нет.

## Чего ещё нет

В меню уже есть пункты, но страниц под них нет:

- **Мой дневник** (`/diary`) — записей об уловах нет, маршрут не заведён.
- **О приложении** (`/about`) — справки нет, маршрут не заведён.

Также нет:

- сохранения чего-либо между перезагрузками;
- настоящих водоёмов и меток на карте;
- карточки рыбы с подробным описанием;
- советов, которые зависят от погоды, а не от зашитого текста;
- сохранённых пресетов прикормки.

Пакет `@fawmi/vue-google-maps` стоит в зависимостях, карта на нём не построена. Старый компонент `mySelect.vue` ещё зарегистрирован рядом с `BaseSelect`.

## С чего продолжить

Имеет смысл идти в таком порядке. Каждый пункт закрывает дыру, которая уже видна в интерфейсе.

1. **Довести карту.** Центр по геолокации пользователя. Метки водоёмов. Клик по строке в списке двигает карту и наоборот. Поиск должен смотреть и в рыб, как обещает плейсхолдер, а не только в название.
2. **Вынести данные из компонентов.** Водоёмы, рыбы и рецепты прикормки сейчас массивы внутри страниц. Отдельные модули или сторы Pinia, по тому же принципу, что уже сделано для погоды.
3. **Справочник рыб.** Уникальные виды, правильные латинские имена, свои фото и иконки. Кнопка «Подробнее» открывает описание: где водится, на что ловить, сезон, температура.
4. **Связать погоду с советами.** Часы клёва, текст «для щуки и окуня», советы на сегодня и блок «Планирование на неделю» должны считаться из прогноза, а не быть константами. Температуру воды либо убрать, либо брать из источника, если он появится.
5. **Прикормка.** Вернуть глубину, если она нужна в подборе. Больше рецептов или правила сборки состава, а не выбор одного из трёх. «Сохранить пресет» пишет в `localStorage`.
6. **Дневник.** Новая страница: дата, место, рыба, снасть, прикормка, заметка. Список записей и форма добавления, хранение локально.
7. **Страница «О приложении».** Короткая справка по четырём разделам, чтобы пункт меню не вёл в пустоту.
8. **Иконки меню.** Отдельный SVG на карту, рыбу, погоду, прикормку, дневник и справку вместо одной `pike`.
9. **Ключи API.** Сейчас ключи Яндекс.Карт, OpenWeather и луны лежат прямо в `src/main.js` и `src/stores/weather.js`. Перенести их в `.env` и не коммитить файл с секретами.
10. **Деплой.** Скрипт `npm run deploy` собирает `dist` через `gh-pages`. Файл workflow лежит в `public/.github/workflows/deploy.yml`. GitHub Actions читает workflow только из `.github/workflows` в корне репозитория, поэтому этот файл из `public` сам по себе пайплайн не запускает.

## Где что лежит

```text
src/
  App.vue                  оболочка, шапки страниц, запрос геолокации
  main.js                  роутер, Pinia, Яндекс.Карты, глобальные компоненты
  router/router.js         четыре маршрута
  stores/weather.js        координаты, погода, прогноз, луна
  pages/                   PageMap, PageFishes, PageWeather, PageBait
  components/sidebar/      меню и блок советов
  components/weather/      Сейчас, Сегодня, Неделя
  components/ui/           кнопки, поля, карточки, списки
  assets/icons/            SVG для спрайта
```
